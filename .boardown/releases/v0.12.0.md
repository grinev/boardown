## CLI: apply a batch of operations from stdin

---
id: BD-107
type: feature
status: todo
epic: cli
order: 175
links:
  - type: relates
    to: BD-130
---

Setting up one board took 23 CLI calls: 4 epics, 10 tasks, 6 checklist items, 2 status marks, 1 link. Each round-trip can fail and leave the board half-built. `boardown apply -` reads a JSON array of operations from stdin and applies them through `writeAll` — all of them or none.

Needs grooming: how an operation references an id created earlier in the same batch, `--dry-run`, the shape of the response (one result per operation), and what happens when a core invariant refuses mid-batch. Widening the published command set is the human's call.

## Browser console shows 404 errors for files that do not exist yet

---
id: BD-138
type: bug
status: todo
order: 300
---

In the web app, opening a task that has no attachments logs 'Failed to load resource: 404' for the task's attachments folder, and saving a task on a board without backlog.md logs the same for backlog.md. Nothing breaks on screen, but every such open or write leaves errors in the browser console. Expected: a file or folder that does not exist yet is a normal state and produces no console error. Seen on the v0.11.0 demo (BD-126).
