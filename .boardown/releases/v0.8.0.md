Merged from BD-98 (first-field focus), BD-102 (Cmd/Ctrl+Enter submit) and BD-99 (width). Scope is the three creation dialogs only — task, epic and release — not every dialog in the app.

Width: the create dialog is capped at 440px. Give it the width of the task dialog's main column (the one holding the description field), not the full task dialog width.

Focus: a creation dialog opens with focus on the header close button instead of its first field. React applies autoFocus at mount, when Modal has not called showModal() yet, so showModal() falls back to the first focusable element. Fix it once in Modal.

Submit: Cmd/Ctrl+Enter submits a creation dialog from any field, matching the inline editors in the task dialog.
