## Show CLI install hint in Settings

---
id: BD-83
type: feature
status: done
order: 550
---

Settings gains a read-only CLI row: the install command (npm i -g @grinev/boardown-cli) plus a Learn more link to the CLI docs on GitHub. No detection of whether the CLI is installed - rejected because PATH is unreliable from a GUI-launched host and a false negative reads as a bug.

Placement: shared Settings dialog (VS Code + web) between the WIP limit field and the Version row; Electron gets a new CLI section at the end of its sidebar settings panel.

Includes the prerequisite fix: the Electron window has no navigation guard, so an external link in rendered markdown (Docs page, doc popup, repo .md preview) currently replaces the board with the remote page and there is no way back. Links must open in the OS browser instead.
