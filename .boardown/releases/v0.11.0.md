    text: "Open fork for this task, surfaced while grooming BD-125: the stamp lands on the first write, but a conversion may need to happen on the first read. Two paths. Keep a reader for the old layout and convert on the first write — BD-125's rule that a read never writes stays intact. Or read only the new layout and convert at load — an open becomes a write, and that rule is amended here. Second reader versus 'boardown task get' rewriting a board it was only asked to read."
    createdAt: "2026-09-08T09:00:15.274Z"
  - id: n2
    text: "Second thing to remember, from the same grooming session. minCompatibleVersion is only set by release:prepare, so between the commit that changes the format and the next release the constant is stale: a build run from source supports the new layout while still stamping the old number. A board converted by such a build would claim to need only the previous version, and a released build would then open it and show an empty backlog — the exact silent failure BD-125 exists to stop. Harmless for every additive change so far, because an under-stamped board still reads correctly; it becomes real with this task, the first non-additive one. No CI check was wanted for it. Note that any shell run from source has this property, the web dev shell included; the project's own board is worked through VS Code and web, and the tester runs from source against its own sandbox."

## CLI: apply a batch of operations from stdin

---
id: BD-107
type: feature
status: todo
epic: cli
order: 400
links:
  - type: relates
    to: BD-130
---

Setting up one board took 23 CLI calls: 4 epics, 10 tasks, 6 checklist items, 2 status marks, 1 link. Each round-trip can fail and leave the board half-built. `boardown apply -` reads a JSON array of operations from stdin and applies them through `writeAll` — all of them or none.

Needs grooming: how an operation references an id created earlier in the same batch, `--dry-run`, the shape of the response (one result per operation), and what happens when a core invariant refuses mid-batch. Widening the published command set is the human's call.
