The usage for `epic add` / `epic edit` shows the color unquoted, `--color #rrggbb` — in `boardown schema`, in `boardown help` and in the USAGE error messages. In bash and PowerShell an unquoted `#` at the start of a word starts a comment, so a command copied from the usage loses the value:

- `boardown epic add X --color #ff0000` creates the epic with the default color, no error;
- `boardown epic edit x --color #ff0000` fails with USAGE: the flag arrives with no value.

Agents build commands from `boardown schema`, so they hit the first case silently. The placeholder is printed in [[repo:packages/cli/src/commands/schema.ts]], [[repo:packages/cli/src/commands/epic.ts]] and [[repo:packages/cli/src/app.ts]].
