## Release v0.12.0

### Board

- **Swimlanes** — A **Swimlanes** dropdown in the Board's release header splits the columns into collapsible lanes by **Epic** or by **Type**, each lane showing its badge or icon and a task count, with the choice saved in `config.yaml` for every shell.
- **Filter the backlog by labels** — The Backlog's filter bar gains a **label** filter that matches tasks carrying any of the picked labels, or **No labels**, alongside status, type, epic and priority.
- **Created and Updated dates** — The task dialog shows when a task was created and last changed, stamped by every edit from the UI or the CLI; a new **Track update date** checkbox in Settings stops the Updated stamp so parallel branches never conflict on it.
- **Hide the Docs tab** — A new **Docs tab** checkbox in Settings hides the tab while keeping the pages on disk, and `[[page]]` links still open them in a popup.
- **Releases in version order** — Releases now sort by version (`v0.9.0` before `v0.10.0`) in the Backlog, the Board switcher, the release pickers and search, and the Archive lists the most recently completed release first.
- **Conflict during onboarding** — If `config.yaml` appears on disk while the setup form is open, Create now offers the Reload conflict dialog instead of an inline error, and never overwrites the file.

### Desktop

- **New settings in the sidebar** — The sidebar's settings gain the same **Track update date** and **Docs tab** checkboxes.

### CLI

- **`task list --label`** — List tasks carrying any of one or more labels, combined with the other filters; an undeclared label fails with `USAGE`.
- **Task dates** — Every command that changes a task stamps its `updatedAt` (unless the board turns tracking off) and a new task its `createdAt`; `task get` prints both and `schema` reports them.
- **Release ordering and dates** — `release start` and `release done` record the start and completion day, `release list` and `backlog` order releases by version, and `archive` lists the most recently completed release first.
- **Agent skill writes docs pages** — The bundled agent skill now lets an agent create and edit pages under `.boardown/docs/` directly.

### Web

- **Embed mode** — Open a board page with `?embed` to drop the project title row, so the board fits inside another app's window.
- **Open a task from the URL** — A board page opened with `#task=BD-12`, or handed that fragment while already open, opens the task's dialog without reloading the page.
- **Shared themes** — `boardown-web --config-dir <path>` applies one theme, built-in or a custom JSON palette, to every board the server serves, and live edits to it show up in open tabs without a reload.
- **Right theme from the first frame** — A board page no longer flashes light before a dark theme while it loads.
- **Quieter browser console** — Opening a board whose files or folders do not exist yet no longer fills the console with 404 errors.
